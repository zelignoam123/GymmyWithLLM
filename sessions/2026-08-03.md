### Architecture decisions made

1. **Static map is the core** — `FEATURE_CUES` dict maps each of 38 features to a positive Hebrew coaching sentence. Zero latency, always works, deterministic.
2. **LLM is an optional wrapper** — takes 3 static cues and rephrases into one natural sentence via Gemini Flash. Falls back to static on failure.
3. **Feature importance via contribution** — `coefficient × standardized_value` per feature, sorted by absolute value, top 3 sent to feedback.
4. **Cross-session improvement** — compare contributions between sessions, positive delta above threshold triggers encouragement.
5. **Human-readable pre-processing** — features are translated to Hebrew cues BEFORE hitting the LLM, reducing prompt cost and removing raw feature names from the LLM context.


## Research findings

- The ML model is a **statsmodels regression** (not sklearn classifier) — has named coefficients accessible via `model.model.data.xnames`
- Feedback happens **intra-session** (real-time), not between sessions
- The trigger condition: `s.corrective_feedback and (s.robot_rep >= s.rep/2) and counter <= 2`
- Adaptation threshold: `sum(scores) > 1.1`
